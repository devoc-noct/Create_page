dictionary

1. CLASS — 空間分類

記号：1～F
class:1 ～ class:5 + class:F
数字を使った分類コード。
数字が大きいほど特殊現実と離れた特殊な空間。
F は通常分類に当てはまらない特殊な空間。

2. STABILITY — 安定性

単位：%
0% ～ 100%
100%：非常に安定している。
50%：不安定な部分がある。
0%：通常の空間として維持できないほど不安定。
数値が高いほど安定している。

3. VOID CONNECTION — void接続確率

単位：%
0% ～ 100%
0%：接続する可能性がない。
1%：接続する可能性は非常に低い。
100%：定義した条件下で必ず接続する。
(その場所がvoidなら、f　と表記する。)
数値が高いほど void につながりやすい。

4. DANGER — 危険度

ランク：A～F
A:安全
B:低危険
C:注意が必要
D:危険
E:極めて危険
F:測定不能・規格外

5. STATUS — 状態

STABLE：安定
UNSTABLE：不安定
COLLAPSING：崩壊中
SEALED：封鎖中
UNKNOWN：状態不明
これは数値ではなく、その場所の現在の状態を示す。
